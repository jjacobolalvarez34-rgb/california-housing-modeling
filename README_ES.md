# california-housing-modeling
Proyecto académico desarrollado durante la asignatura Modelación y Simulación 1 de la carrera de Matemáticas.

El objetivo del proyecto fue analizar un conjunto de datos de viviendas y construir modelos predictivos capaces de estimar el precio de una propiedad a partir de sus características físicas, geográficas y socioeconómicas.

# Objetivos
- Realizar análisis exploratorio de datos (EDA).
- Identificar variables relevantes para la predicción.
- Aplicar técnicas de preprocesamiento y limpieza de datos.
- Construir y comparar diferentes modelos predictivos.
- Evaluar el desempeño mediante métricas de regresión.
- Analizar problemas de sobreajuste y subajuste.
- Técnicas utilizadas
- Análisis Exploratorio de Datos (EDA)
- Estadística descriptiva
- Detección de valores atípicos
- Matriz de correlación
- Visualización de variables
- Análisis geográfico mediante latitud y longitud
- Preprocesamiento
- Imputación de valores faltantes
- One-Hot Encoding
- Escalamiento de variables
- Selección de características
- Modelos implementados
- Regresión Lineal
- Regresión Ridge
- Regresión Lasso
- Regresión Polinómica
- Random Forest Regressor
- Redes Neuronales (MLP)
- Optimización
- Ajuste de hiperparámetros
- Comparación de modelos
- Evaluación de desempeño
- Métricas de evaluación
- R² (Coeficiente de Determinación)
- RMSE (Root Mean Squared Error)
- MAE (Mean Absolute Error)
- Herramientas utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- TensorFlow / Keras (si realmente lo usaste)
# Resultados

Se compararon múltiples enfoques de modelación para identificar la metodología con mejor capacidad predictiva sobre el conjunto de datos estudiado.

El proyecto permitió evaluar el impacto de distintas técnicas de preprocesamiento, selección de variables y ajuste de hiperparámetros sobre el desempeño final de los modelos.
